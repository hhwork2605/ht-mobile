# P3-05 Đa ngôn ngữ VI/EN

- **Phase:** 3 (chuyển từ Phase 4)
- **Tính năng SPEC:** §1, §3 (/changelanguage), §9 (LangSwitcher); conventions §Đa ngôn ngữ
- **Trạng thái:** doing

## Mục tiêu
Người dùng đổi ngôn ngữ giao diện **VI ⇄ EN**; chuỗi UI dịch qua `.resx` + `IStringLocalizer`. Lựa chọn lưu cookie,
giữ qua các request. Cơ chế (switcher + resx) hoạt động end-to-end trên các chuỗi UI chính.

## Phạm vi (in-scope)
- [ ] ASP.NET Core Request Localization: culture **vi (mặc định) + en**; `CookieRequestCultureProvider` (.AspNetCore.Culture).
- [ ] Helper thuần `LanguageOptions`: `Supported={vi,en}`, `Default=vi`, `Resolve(code)` (case-insensitive; lạ/null → mặc định). Có test.
- [ ] Route `GET /changelanguage?culture=&returnUrl=`: set cookie culture (chỉ culture hợp lệ) → redirect `UrlSafety.SafeLocalUrl(returnUrl)`.
- [ ] LangSwitcher ở header (`_Layout`): VI | EN, đánh dấu ngôn ngữ đang dùng, giữ trang hiện tại (returnUrl).
- [ ] `SharedResource` + `Resources/SharedResource.resx` (vi) + `SharedResource.en.resx` (en); localize **chuỗi UI chính**
      (header: tìm kiếm/tài khoản/giỏ; footer cột + mô tả; vài nút/nhãn chung). `<html lang>` theo culture hiện tại.

## Ngoài phạm vi (out-of-scope)
- Dịch **nội dung DB** (tên SP, mô tả… qua entity `Translation`) — hoãn (khối lượng lớn; demo cơ chế trên chuỗi UI trước).
- URL theo locale (`/en/...`) + hreflang en — giữ cookie-based (cùng URL), hreflang vi/x-default như hiện tại.
- Dịch 100% mọi chuỗi — localize tập đại diện; phần còn lại bổ sung dần.
